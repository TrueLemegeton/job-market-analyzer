# Job Market Analyzer

Личный сервис для анализа рынка IT-вакансий.

На текущем этапе проект ориентирован на вакансии Python-разработчиков с HH.ru. Сервис собирает реальные данные о вакансиях, которые в дальнейшем будут использоваться для анализа рынка труда.

## Цель проекта

Создать собственный инструмент, который позволяет анализировать рынок Python-вакансий на основе большого количества реальных данных.

В перспективе сервис должен помогать отвечать на вопросы:

- какие технологии наиболее востребованы;
- какие навыки чаще всего требуют работодатели;
- какие требования предъявляются к Junior, Middle и Senior разработчикам;
- какие зарплаты предлагают работодатели;
- как меняется спрос на технологии со временем;
- какие навыки стоит изучать для развития в Python-разработке.

Главная особенность проекта — анализ собственных собранных данных, а не использование общих оценок и предположений нейронных сетей.

## Текущий этап

Сейчас реализован сбор данных с HH.ru.

Проект использует Playwright для получения ссылок на вакансии и Requests + BeautifulSoup для дальнейшего получения и обработки HTML-страниц вакансий.

### Уже реализовано

- поиск Python-вакансий;
- сбор ссылок на вакансии;
- получение страницы отдельной вакансии;
- извлечение названия вакансии;
- извлечение зарплаты;
- определение зарплаты до или после вычета налогов (`gross` / `net`);
- извлечение названия компании;
- извлечение требуемого опыта работы;
- извлечение типа занятости;
- извлечение графика работы;
- извлечение формата работы;
- извлечение формата оформления;
- извлечение ключевых навыков.

## Планируемая архитектура

```text
HH.ru
   ↓
Playwright
   ↓
Поиск вакансий и сбор ссылок
   ↓
Requests
   ↓
Получение HTML вакансий
   ↓
BeautifulSoup
   ↓
Извлечение структурированных данных
   ↓
Хранение вакансий
   ↓
Обработка описаний локальной LLM
   ↓
Структурированные требования и навыки
   ↓
Анализ рынка Python-разработки
   ↓
Личный сервис
````

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/TrueLemegeton/job-market-analyzer
cd job-market-analyzer
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.venv\Scripts\activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Установка браузера для Playwright

```bash
playwright install chromium
```

### 6. Запуск

```bash
python src/main.py
```
